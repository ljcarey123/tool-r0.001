# Results explorer

A static site, served by GitHub Pages from this `docs/` folder, for exploring the architecture and results. It has no build step and no dependencies: plain HTML, CSS and ES modules.

## View it locally

ES modules and `fetch` need a web server, not `file://`:

```bash
python -m http.server 8765 -d docs     # then open http://localhost:8765
```

## Regenerate the data

`data/*.json` is generated from the training logs and comparison results in `runs/`:

```bash
# per-example outputs for the example browser (about 45 min on a 4 GB GPU)
python scripts/eval_compare.py --checkpoint runs/full2/solver --splits live_simple,simple \
  --variants trained/paper,base/paper,base/paper+nothink,base/qwen \
  --save-outputs runs/outputs-full2.json

python scripts/build_explorer_data.py
```

## Structure

```
index.html            page shell: nav, an empty <main>, the stylesheets and one module script
css/
  tokens.css          every colour, size and font, with light and dark values; nothing else
  base.css            element defaults and page layout
  components.css      reusable components (card, segmented control, table, badge, …)
  charts.css          chart marks, bar lists and the tooltip
  sections.css        layout that belongs to one section only
js/
  main.js             renders each section in order; one failing section doesn't break the rest
  config.js           repo URL and the fixed colour of each model variant
  theme.js            light/dark toggle
  lib/                no knowledge of this project
    dom.js            h() / s() element builders, mount(), segmented(), onResize()
    charts.js         barList(), lineChart(), columnChart(), legend()
    tooltip.js        one shared tooltip
    data.js           cached fetch of data/<name>.json
    format.js         number and p-value formatting
    layout.js         section(), card(), codeLinks()
  content/            the words, kept apart from the layout code
    stages.js         the self-play stages for the architecture section
    story.js          the four steps of the results narrative
  sections/           one module per page section; each exports render() → element
    overview.js  architecture.js  results.js  training.js  examples.js
data/                 generated by scripts/build_explorer_data.py
```

Conventions:
- **Sections are independent.** A section imports from `lib/`, `content/` and `config.js`, never from another section. Add one by writing `sections/<name>.js` with an exported `render()`, then listing it in `main.js` and the nav in `index.html`.
- **Styles use tokens.** Components read roles like `--ink` or `--series-1`, never raw colours, so dark mode lives entirely in `tokens.css`. Class names follow `block__part` with `is-*` states.
- **Colour follows the model variant** (`config.js`), so a variant has the same colour in every chart.
